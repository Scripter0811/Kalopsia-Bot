# Xenfire Bot ♣️

[![Xenfire Bot](https://img.shields.io/badge/Xenfire-Bot-7289DA?style=for-the-badge&logo=discord)](https://github.com/Monochromish/Xenfire-Bot)

Xenfire Bot is an open-source Discord.js v13 bot with a variety of features, including:

- Slash commands
- Staff commands
- Fun and entertaining commands
- Utility commands
- Economy system
- MongoDB integration

## Prerequisites

To use and develop Xenfire Bot, you will need:

- [Node.js](https://nodejs.org)
- [Yarn](https://yarnpkg.com) (recommended, although NPM can also be used)
- [Git](https://git-scm.com) (optional, you can also just download the repository directly)
- [MongoDB](https://www.mongodb.com/atlas/database)
- Experience with [JavaScript](https://www.learn-js.org) and [Discord.js](https://discord.js.org) (preferably Discord.js v13)

## Getting Started

To set up Xenfire Bot on your machine:

1. Clone or download the repository
2. Modify the `example.env` file and rename it to `.env`
3. Install the necessary dependencies using your package manager
4. Run the bot
